# build-your-own-sqlite-in-go

Go で SQLite の内部構造を理解するための学習プロジェクトです。中核的なデータベースの概念を小さく再実装し、仕組みを学べるようにしています。

## 概要

このリポジトリは、次のようなテーマを学ぶための学習用プロジェクトです。

- ストレージとページレイアウト
- SQL の解析と実行計画
- テーブルとインデックスの構造
- トランザクションと耐久性
- B-tree の内部動作
- 基本的なクエリ実行エンジンの挙動

本来の SQLite を完全に再現することが目的ではなく、軽量なデータベースエンジンの設計思想とアーキテクチャを説明できるように、シンプルな実装を目指します。

## プロジェクトの目標

- SQLite がディスク上でデータを保存・取得する方法を学ぶ
- SQL 文がどのように解析されて実行されるかを理解する
- B-tree やテーブルページの仕組みを調べる
- Go で小さくても実用的なデータベースエンジンを作る
- 学習しやすく、拡張しやすい形に保つ

## 典型的な構成

このリポジトリは、開発が進むにつれてシンプルな形を保ちながら拡張していくことを想定しています。典型的な構成は次のとおりです。

```text
.
```

## はじめ方

必要に応じて Go モジュールを初期化します。

```bash
go mod init github.com/<your-user>/build-your-own-sqlite-in-go
```

その後、プロジェクトを実行します。

```bash
go run ./...
```

特定のパッケージだけを実行したい場合は次のようにします。

```bash
go run ./cmd/app
```

## 開発の流れの例

このプロジェクトでは、次のような順番で開発を進めるのが自然です。

1. ストレージ形式やページレイアウトを定義する
2. 最小限の SQL パーサやトークナイザを実装する
3. レコード保存とテーブル/ページアクセスを追加する
4. INSERT / SELECT / UPDATE の動作を実装する
5. 小さなテストで正しさを確認する
6. トランザクションやインデックス、クエリ改善を追加する

## 開発メモ

このプロジェクトは段階的に進めるのが適しています。1 つの概念に集中して実装するのが理解しやすく、例えば次のような観点で進めます。

- ページ形式とファイル I/O
- レコードの符号化と復号
- テーブル走査と行取得
- SQL 文の実行
- トランザクション処理

## テスト

Go 標準のツールを使ってテストを実行できます。

```bash
go test ./...
```

開発中は対象範囲だけをテストすることもできます。

```bash
go test ./internal/... -v
```
